# Explore the Future

Nätverk och think tank för samtal om samtiden och framtiden.

Repo: [github.com/Power8squid/explore-the-future](https://github.com/Power8squid/explore-the-future)

## Sidan

Startsidan samlar tre överblickskort över ämnen vi har utforskat, plus en intresseanmälan med Discord-handle.

Intresseanmälan skickas till Discord via webhook. Kopiera `config.example.php` till `config.php` och fyll i nycklarna innan formuläret kan användas på en PHP-host.

## Köra lokalt

Öppna `index.html` i webbläsaren, eller med PHP:

```bash
php -S localhost:8080
```

Gå sedan till `http://localhost:8080`.
